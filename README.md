# undergrad

High-quality animated content for undergraduate math, biology, and physics.

## Purpose

`undergrad` creates explanatory content covering core undergraduate curricula
in mathematics, biology, and physics, with a focus on **high-quality
animations** that make abstract ideas concrete.

- **Multi-disciplinary** — math, biology, and physics at the undergraduate
  level.
- **Animation-first** — visual, animated explanations (think 3Blue1Brown-style
  motion) as the primary teaching tool.
- **Quality over quantity** — polished, carefully-crafted pieces.

## Goals

- Make undergraduate-level concepts intuitive through motion and visualization.
- Build a reusable pipeline for producing animated educational content.

## Status

Early / scaffolding. This directory currently holds only project intent.
